duckmetrics — client-side analytics

This page runs SQL in your browser against the server's Parquet exports (metrics_cold_*.parquet) using @duckdb/duckdb-wasm (client-side query engine only — the server itself is pure Rust). The easiest source is the crate's GET /telemetry/parquet endpoint (see parquet_route), which always serves the newest export; to browse older files, serve the export dir from Axum, e.g. ServeDir::new("./data") mounted at /export, then open this file against the same host (or adjust the URL below).

SELECT
  date_trunc('hour', ts) AS hour,
  name,
  count(*) AS n,
  avg(value) AS avg_value,
  max(value) AS max_value
FROM read_parquet('PQ')
GROUP BY 1, 2
ORDER BY 1 DESC, 2
LIMIT 100;
